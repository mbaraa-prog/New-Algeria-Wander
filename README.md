-----Algeria Wander-----

Description

Algeria Wander is a tourism web platform (travel guide) designed to help users discover and explore destinations across Algeria. The platform provides information about tourist attractions, hotels, restaurants, and events through a modern and user-friendly interface.

The main objective of the project is to promote Algerian tourism by centralizing useful travel information in a single platform.

Main Features
 Visitors:

-Browse tourist destinations.
-Explore hotels, restaurants, and other places.
-Search for places and destinations.
-View detailed information about each location.
-Browse locations by category.

 Registered Users:

-Create an account.
-Log in and log out.
-Manage their profile.
-Add places to favorites.
-View their list of favorite places.
-Write and view reviews.

 Content Management:
 
-View tourism-related events.
-Display places dynamically from the database.
-Organize places into categories (Hotels, Restaurants, and Others).

Technologies Used:

Frontend:
-React
-Vite
-JavaScript
-CSS
Backend:
-Django

How to Test the Project
1. Access the Application

Open the frontend URL in any web browser.

2. Test the Main Features
   
-Navigate through the homepage.
-Explore different categories of places.
-View detailed information about destinations.
-Search for tourist attractions and locations.
-Create a user account.
-Log in to the platform.
-Add places to favorites.
-Add a blog.
-Share your opinions.
-Add a comment.
-Browse available events.
-Write and read reviews.

3. Verify Data Persistence

All application data is stored in a PostgreSQL database hosted on Render and accessed through the Django REST API.
