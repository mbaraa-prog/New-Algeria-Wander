## Deployment Steps

1. **Prepare Render**:
   - Create new Web Service pointing to this repository
   - Connect to PostgreSQL database (auto-generates DATABASE_URL)
   - Set environment variables in Render dashboard

2. **Deploy**:
   - Push to main branch
   - Render automatically builds and deploys via render.yaml

3. **Verify**:
   - Check `algeria-wander-hods.onrender.com` is accessible
   - Test API endpoints
   - Test media file serving (`/media/...`)
   - Test CORS from Vercel frontend

## Troubleshooting

### 502 Bad Gateway
- Check build logs for errors
- Verify environment variables are set correctly
- Check `python manage.py migrate` ran successfully

### Media files not loading
- Ensure WhiteNoise middleware is enabled
- Check `MEDIA_URL` and `MEDIA_ROOT` in settings.py
- Verify media files exist in backend/media/

### CORS errors
- Verify frontend domain in `CORS_ALLOWED_ORIGINS`
- Ensure it's `https://algeria-wander.vercel.app` (not http)

### 404 on API endpoints
- Check build command ran `python manage.py collectstatic`
- Verify all migrations completed successfully
